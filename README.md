# Tohu Battle Royale

Minecraft Bedrock Edition add-on for TBR-001.

## Repository layout

- `behavior_pack/` — Behavior Pack and Script API implementation
- `resource_pack/` — Resource Pack assets and manifest

The `development_*` folders in the Minecraft workspace are local development copies and are intentionally not tracked here. Changes should be copied into the corresponding repository pack before committing.

## Target

- Minecraft Bedrock Edition
- `@minecraft/server` `2.12.0-beta`
- Behavior Pack: `behavior_pack/manifest.json`
- Resource Pack: `resource_pack/manifest.json`
